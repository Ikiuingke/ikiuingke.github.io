#+TITLE: vinyl-finder
The pages of the https://vinyl-finder.gitlab.io website.

* Development
This site is using =@sctlib/emacs-ssg= to generate the pages, =emacs=,
=inotify-tools= and =python= are the dependencies.

- =npm install=
- =npm run dev=

* OS (open search)
There is a description in the =./assets/= folder.

* CSE (google custom search engine)
This project uses [[https://cse.google.com/cse/all][Google Custom Search]].

To update and add new =annotation.xml= into the CSE, it has to be done
manually through [[https://cse.google.com/][cse.google.com]].

The generation can be managed with the CMS.
